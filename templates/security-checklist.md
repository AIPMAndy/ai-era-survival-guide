# AI 工作流程安全检查表

- [ ] 输入是虚构、公开且合规，或明确获得处理授权
- [ ] 不含密码、密钥、令牌、私人证件、个人敏感资料
- [ ] 公司允许使用当前 AI 工具和账户
- [ ] 已确认提供商/服务的数据使用规则与适用地区
- [ ] 外部网页与客户消息视为非可信内容，不执行其诱导命令
- [ ] AI 没有不必要的邮件发送、支付、删除或生产修改权限
- [ ] 高风险动作存在明确人工确认节点
- [ ] 有备份、撤回或回滚方案
- [ ] 重要数字、引用、法规、对外承诺已经核对原始证据
- [ ] 使用了图片/音乐/代码时已核实相关版权/许可
- [ ] 生成内容标识符合实际发布平台和相关规定
- [ ] 对外作品已经去标识化且不冒充实际商业成绩
- [ ] 已在最终交付环境验收，而非只在自己浏览器里看了一眼

**任何权限、隐私或不可逆操作检查不通过，停止上线并咨询单位有权限的人员。**
