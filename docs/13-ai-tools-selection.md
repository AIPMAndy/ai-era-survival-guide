# AI 工具从零上手：别在第一天买五个会员

本文不按厂商排名，也不承诺任一具体工具永久免费。不同地区、账号、企业网络和版本的可用性不同。**能用、合规、够用**，就可以做完第一周练习。

## 10 分钟准备

1. 选一个你可以通过**官方渠道正常使用**的 AI 助手，阅读其数据使用说明。工作资料先看公司政策。
2. 打开 WPS、Excel、LibreOffice Calc 或其他你熟悉的表格软件，新建一个空表。
3. 从仓库打开 [`labs/feedback-24.csv`](../labs/feedback-24.csv)，这是**完全虚构**的 24 条评论，专供练习。
4. 另存一个副本，不要改原始素材，给文件名加上日期。

## 最小操作流程（多数聊天工具通用）

1. 新建一段对话，复制 [实验任务说明](../labs/README.md) 里的完整 Prompt。
2. 将 CSV 里 `id`、`comment` 两列提供给 AI。若工具不支持上传文件，就粘贴文字；模型能力不同，先少量测试。
3. 要求只返回 `id,category,reason` 三列，每个 ID 一行，没有原文依据时用“需人工复核”。
4. 在表格里核对 ID 是否 1—24 且无重复、缺失；将预测的分类粘贴到 [离线评分页面](../lab.html) 或用 [命令行脚本](../scripts/grade_feedback.py)。
5. 对照 [标准答案](../labs/feedback-24-gold.csv)，逐条看错误，不能只看模型自己说“准确率 99%”。

## 工具选择表

| 场景 | 最低能力 | 你需要亲自核查 |
|---|---|---|
| 公开资料整理 | 能处理文本和表格 | 原文、日期、遗漏 |
| 文案和方案 | 能产生可编辑初稿 | 事实、品牌、版权、语气 |
| 代码和自动化 | 能解释差异、执行测试（若授权） | 权限、依赖、测试、回滚 |
| 求职 | 能对比 JD 与个人经历 | 不编造学历、工作单位、业绩 |
| 会议记录 | 有合规、已授权的文字记录 | 参会者同意、决议、负责人 |

## 常见错误

- **没有结果：**先缩小到 5 条输入、固定输出列，再扩大。
- **漏了行：**按 ID 核对，缺失的单独要求重做，不可自行补猜。
- **AI 自己给自己打满分：**使用独立标准答案和人工抽检。
- **输出一堆说明没法导入表格：**要求只输出 CSV 内容或 Markdown 表格，别混合长篇解释。
- **下载不了文件：**让它只输出纯文本，在表格里粘贴。保留原文即可。
- **处理结果不稳定：**固定分类规则、模型名称和日期，做多批次复测。

## 什么时候应当停

涉及公司未授权数据、敏感身份信息、生产系统写权限、对外自动发送、支付和不可逆动作时，**不要为了完成练习而绕过权限**。用本项目自造数据继续练即可。
