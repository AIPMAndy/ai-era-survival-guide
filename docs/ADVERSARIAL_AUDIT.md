# 对抗式审核记录 · 2026-10-12

项目版本：**2.0 深度研究版**。审核对象包括公开研究、完整文章、静态站、可复制 Prompt、课堂数据、评分工具、隐私安全及求职练习。

这是一份**自我质疑和修订记录**，不是经过第三方审计认证。完成部分静态测试不代表真实业务效果或线上运行已经验证。

## 审核方法

1. **就业研究反方**：假设“AI 能力增强”不一定意味着岗位安全，寻找相反数据。
2. **没有 AI 经验的读者**：假设他只用手机/不会 CSV/没有购买会员预算，看能否从第一天开始。
3. **正失业的读者**：假设下个月房租马上到期，看教程是否误导其暂停投递去买课。
4. **企业安全负责人**：假设员工把客户资料发给外部工具、让 Agent 自动发布或删库，能否提前阻止。
5. **面试官**：假设作品完全由 AI 代写或使用虚构数据，能否追问出真实能力。
6. **测试工程师**：假设 AI 给出重复行、漏行、错误标签、错位输出，能否由程序发现。
7. **事实核查者**：对每个数字追溯对象、时间、方法及外推限制。

## 第四轮：程序与材料审查

必须通过：`python3 scripts/check_content.py`、`python3 -m unittest discover -s tests -v`、对演示 CSV 运行评分工具，并用 `node --check` 检查首页和实验页脚本。检测覆盖：本地图片和链接、封面尺寸、实验样本数量、示范错项数量、重复 ID、无效标签、遗漏 ID。

**浏览器仍需复核的项目：**手机宽度是否溢出、静态页图像显示、复选框是否能本地保存与重置、实验评分按钮点击、页面链接在真实 GitHub Pages 下是否正确。没有经过线上发布就不能声称线上实测通过。

## 审核后的剩余限制

- 研究受样本、地区、研究年份、工具迭代影响；不能算个人失业概率。
- 24 条虚构反馈的教学标签是人工规定的，不是业务客观真理；实验也不能代表真实客服系统质量。
- 工作与薪资建议未读取读者个人实际数据，不构成定制职业咨询或投资/法律建议。
- 中国大陆政策与用人单位内部制度可能更新，需要在使用现场核实。
- 当前仍是**可发布项目文件**；GitHub 仓库与 Pages 是否在线，应单独验证。

## 审稿人最后一个问题

**一个今天完全不会用 AI 的人，能否在 7 天后拿出真实、有来源、能复核的作品？**

本项目提供最小路径：24 条虚构评论 → 固定任务标准 → 人工基线 → AI 分类 → 独立评分 → 错误复核 → 可展示练习报告。最后如果结果是“变慢、做错、应当停”，这也必须如实保留。


## v3.0 反方审核：政策、案例、因果

- **政策夸大：**全国 3000 万人次培训目标不等于每人有补贴，已逐条增加地方资格、官方渠道核验和有效期警告。
- **案例营销：**Klarna 所谓“等效 700 人”不应冒充实际裁员 700 人，已经只用于说明自述与服务质量分开。
- **研究外推：**NBER 客服、BCG 顾问、METR 资深开发者测量不同指标，不允许直接并列算平均提效。
- **青年就业因果：**Anthropic 和 Stanford 的美国数据有年龄、地区与时间口径限制，不能直接推断中国个人失业概率。
- **隐私与内容合规：**法律规范约束如何使用数据和发布内容，不代表任何工具经过安全审核。
- **真正能操作：**新增政策办理核验表、案例反向检查卡与 JD 证据表，供读者保留来源。

**未被解决的限制：**没有当地实时补贴名额和个人资格信息；没有用户企业的任务数据；不能为读者断言一定能保住工作。原始依据见 [来源与限制](SOURCES.md)。
