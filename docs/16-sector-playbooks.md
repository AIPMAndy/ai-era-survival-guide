# 十个常见岗位：第一项 AI 练习做什么？

这是练习选题表，**不是职业淘汰排行榜**。同一岗位在不同企业的权限、数据和工作内容差别很大；请从自己真的干过的任务挑。

| 岗位 | 先练什么 | 必须自己检查 | 可展示的证据 |
|---|---|---|---|
| 行政助理 | 公开信息整理、会议模拟纪要 | 决议、责任人与截止日期 | 一份更正记录与标准纪要 |
| 人力资源 | 公开 JD 分析与技能分类 | 用语、招聘歧视风险、私人简历权限 | JD → 能力矩阵 |
| 客服 | 虚构 FAQ 分类与回复草稿 | 政策承诺、敏感投诉、客户隐私 | 带严重问题升级规则的 FAQ |
| 内容运营 | 公开评论主题分类 | 原文忠实、来源、生成标识 | 24 条样本与错误复核表 |
| 销售/商务 | 公开公司信息研究与邮件草稿 | 联系方式合法来源、事实、承诺 | 一份账户研究与沟通提纲 |
| 财务/采购 | 虚构报价表核对 | 计算公式、合同、授权 | 报价差异与异常清单 |
| 教师/培训 | 公开教材的练习题草稿 | 正确性、年龄适宜、版权 | 题目与人工答案核对 |
| 产品经理 | 公开产品流程拆解 | 用户研究是否真实、指标口径 | 原型、测试记录与取舍 |
| 设计师 | 公开资料建立设计 brief | 授权、品牌一致性、手动修订 | brief→迭代前后稿 |
| 程序员 | 小型开源仓库文档与测试 | 测试、依赖、安全、许可 | 可复现的 PR、测试日志 |

## 怎么判断一个练习值得继续

先检查数据是否合规，再确认结果能核实，然后在同类任务上测 **T0（人工）** 和 **T1（AI 总耗时）**。最后问一个真实的人能否理解成果。如果只能给自己看、不知道错误在哪里，就继续缩小任务。

## 不适合照做的事情

未经授权让 Agent 读取公司 CRM、HR 系统、财务系统；让 AI 独立做员工录用/辞退决定；把客户投诉或医疗、法律、财务判断交给模型自动回复；在真实环境直接批量群发或修改生产配置。
