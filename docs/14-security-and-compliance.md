# 公司资料、隐私与对外发布：安全检查单

AI 辅助工作最常见的风险，并非“不会写 Prompt”，而是上传了不该上传的材料、相信了错误内容，或让自动化执行了不可恢复的动作。

## 输入前：五级检查

| 数据 | 能否直接输入公开外部 AI | 较安全的替代方式 |
|---|---|---|
| 你自己编写的虚构样本 | 通常可以，仍遵守平台协议 | 最适合初学者 |
| 已公开且可合法使用的文本 | 视版权、用途与平台政策而定 | 保留公开链接与引用边界 |
| 客户名单、个人手机号、身份证、病历 | **不应直接上传** | 取得合法授权并按政策处理；练习改用虚构样本 |
| 未公开内部文档、合同、财务和源代码 | **没有明确审批就停** | 企业批准的环境、访问控制和脱敏流程 |
| 密码、API Key、Cookie、私钥 | **绝对不要粘贴** | 使用密钥管理器与最小权限，泄露则立即轮换 |

## 给 Agent 权限前

- 权限最小化：优先只读、隔离测试环境、无支付和发送权限。
- 明确人审节点：删除、发布、付款、改权限、外发邮件必须事先得到可追溯的人工批准。
- 有回滚方案：改文件先备份、修改代码保留 Git 版本、生产操作有负责人。
- 将网页、邮件、附件、仓库 README 当成**不可信输入**，可能包含诱导模型泄露信息或越权操作的提示词。
- 记录调用范围、错误、成本；异常立即停用与撤销授权。

## 中国大陆发布与工作场景

2023 年《生成式人工智能服务管理暂行办法》涉及生成式 AI 服务的数据、个人信息、商业秘密等要求。2025 年《人工智能生成合成内容标识办法》自 9 月 1 日起实施，对相关服务和发布活动的内容标识提出要求。具体义务因服务类型、发布方式和最新平台规则不同，实施前阅读法规全文及所在平台规范。

不能因某段内容“由 AI 生成”，就以为它自动获得版权许可。引用图片、音乐、代码与他人个人材料，仍应核查合法来源、授权及适用许可。不要未经同意批量采集用户资料或向招聘企业冒充真实工作案例。

## “没出错”不是合格验收

至少检查：是否有权限、是否符合输入范围、是否泄露隐私、输出事实是否有出处、每个重要数字是否可复核、能否在最终使用平台正常运行、是否可以撤回或纠正错误。

**真实业务上线前**请由所在单位负责信息安全、隐私和法律事务的人员检查。此处是学习用检查清单，不替代合规审查。
