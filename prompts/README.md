## 使用时注意

- 有原始材料再给 AI，不要把模拟输出当成真实工作记录。
- 内部数据和客户个人资料，先按企业政策处理。
- 模型、日期、输入大小和人工修订要保留。
- 任何“节省时间”的结论都应计入复核与返工。
