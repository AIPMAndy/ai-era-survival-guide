# AI时代不被淘汰保姆级攻略

![AI时代不被淘汰保姆级攻略](assets/cover-v6.svg)

**普通人未来3年该如何应对**

这是我对中国职场 2027—2029 年的判断，结合政策、招聘数据、企业应用和多年来做 AI 产品、职业咨询的经历整理。

我认为大多数普通人应先守住自己的主业，把 AI 真正用于每天的工作，争取从执行任务走向负责结果。同时从已有的行业经验出发，逐步建立第二收入。
