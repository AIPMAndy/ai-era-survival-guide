## 看完能做到什么

- 把你实际做的工作拆成 15—30 个具体任务，区分输入、产出、权限和验收人。
- 选出 1 个低风险、重复、能验证结果的 AI 辅助任务，不靠职位名称猜“失业概率”。
- 对同一类任务完成一次**人工基线 → AI 辅助 → 人工复核**对照，记录用时和错误。
- 把你的操作留成匿名的 **2—3 页可展示作品**，用于内部汇报或求职。
- 设计未来 **7 天 / 30 天 / 90 天**的练习和职业选择，不把学工具当成唯一目标。

## 如何使用仓库

点击 **Code → Download ZIP**，解压后打开 `index.html`，可在浏览器离线使用 7 天任务清单；打卡只保存在当前浏览器的本地存储里。阅读完整教程打开 `article.html` 或 `GUIDE.md`。

复制 [Prompt 指令](prompts/README.md) 时，记得填写真实材料；没有数据就写未知。复制 [模板](templates/README.md) 到自己的文件夹，再开始记录。不要上传客户信息到公开 GitHub 仓库。

如需在线发布，仓库 **Settings → Pages → Deploy from a branch → main / (root)**，详情见 [PUBLISH.md](PUBLISH.md)。部署状态以 GitHub Actions 与正式网址的实际验收结果为准。

## 用数字之前，请先看来源

国际劳工组织 2025 年发现，全球约四分之一工作受到不同程度生成式 AI 的**任务暴露**影响，更常见的影响可能是工作改造。世界经济论坛预计至 2030 年，现有工作技能约 39% 将发生变化或过时；数字来自企业调查预测，包含多种驱动因素。**两个数字都不能理解成“有多少人一定失业”。**详见 [原始报告与解释](docs/SOURCES.md)。
